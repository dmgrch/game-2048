# 2048

2048 - учебная веб-версия классической игры 2048, разработанная в рамках лабораторной работы по веб-программированию.

Игровое поле состоит из сетки 4×4, которая динамически создается с помощью JavaScript. Пользователь может перемещать плитки в четырех направлениях, объединять одинаковые значения и набирать очки.

На компьютере управление осуществляется стрелками клавиатуры, а на мобильных устройствах — свайпами по игровому полю.

В приложении реализованы:

- классическая логика перемещения и слияния плиток;
- случайное появление новых плиток со значениями 2 и 4;
- подсчет текущего количества очков;
- проверка окончания игры;
- начало новой игры без перезагрузки страницы;
- отмена последнего хода;
- сохранение игровой сессии в localStorage;
- восстановление игры после перезагрузки страницы;
- сохранение результатов игроков;
- таблица топ-10 рекордов;
- плавные анимации движения, появления и слияния плиток;
- адаптивный интерфейс для компьютеров, планшетов и смартфонов.
